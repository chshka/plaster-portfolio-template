# 关联的建站技能

技能名称：`relief-portfolio`。用于AI制作和调整浮雕作品集。技能安装、提示词与使用方法以技能仓库README为准。

公开技能仓库：[`chshka/relief-portfolio`](https://github.com/chshka/relief-portfolio)。

该技能负责指导素材准备、浮雕建模、页面交互、验证与静态部署。当前仓库提供可直接部署的网站源码，两者可以配合使用；安装和提示词请以技能仓库 README 为准。

此网页是独立静态项目，运行无需技能包，也无需REA、Blender、Three.js或GSAP。Blender只用于离线制作模型。
